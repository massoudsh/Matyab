# Roadmap — متریاب (MatYab)

مبنای تاریخ: هفته‌ی جاری (2026-07-27). تخمین‌ها بر اساس تیم کوچک (۲ تا ۴ نفر) است.

---

## فاز ۰ — کشف و اعتبارسنجی (۲ تا ۳ هفته)
هدف: قبل از نوشتن کد زیاد، مطمئن شویم پیمانکاران/تأمین‌کنندگان واقعاً مصالح مازاد را ثبت می‌کنند و به قیمت پیشنهادی اعتماد می‌کنند.

- [ ] مصاحبه با ۱۵-۲۰ پیمانکار/انبارداری درباره‌ی مصالح مازاد فعلی‌شان
- [ ] تعریف دقیق «دسته‌های مصالح فاز اول» (مثلاً: میلگرد، سیمان/بلوک، کاشی و سرامیک، درب و پنجره، لوله و اتصالات)
- [ ] انتخاب یک منطقه‌ی پایلوت (پیشنهاد: تهران و حومه — چگالی پروژه بالا)
- [ ] لندینگ‌پیج ساده + فرم ثبت مصالح مازاد برای سنجش تقاضا
- [ ] خروجی: Go/No-Go برای فاز MVP

## فاز ۱ — MVP (۸ تا ۱۰ هفته)
هدف: اثبات حلقه‌ی اصلی «ثبت عرضه → ثبت تقاضا → مچ دستی/نیمه‌خودکار → تماس مستقیم». بدون پرداخت آنلاین، بدون AI پیچیده.

- [ ] احراز هویت پایه (ثبت‌نام/ورود، نقش خریدار/فروشنده)
- [ ] ثبت آگهی عرضه‌ی مصالح (عکس، دسته، مقدار، واحد، وضعیت کیفی توسط خودِ کاربر، قیمت پیشنهادی خودِ کاربر، شهر/منطقه)
- [ ] ثبت درخواست تقاضا (دسته، مقدار مورد نیاز، بودجه، شهر/منطقه، مهلت)
- [ ] لیست و جست‌وجوی آگهی‌ها (فیلتر دسته/شهر/قیمت)
- [ ] مچینگ نیمه‌خودکار ساده (rule-based: دسته یکسان + فاصله‌ی نزدیک + هم‌پوشانی مقدار)
- [ ] نمایش اطلاعات تماس بعد از ابراز تمایل دو طرف (بدون واسطه‌ی پرداخت)
- [ ] پنل ادمین ساده برای تأیید آگهی‌ها (جلوگیری از اسپم)
- [ ] خروجی: پایلوت زنده در یک منطقه با تعداد محدود پروژه

## فاز ۲ — V1 (۱۰ تا ۱۲ هفته بعد از MVP)
هدف: لایه‌ی هوشمند واقعی — همان چیزی که مزیت رقابتی محصول است.

- [ ] Quality Scoring از روی عکس‌ها (مدل/سرویس امتیازدهی کیفیت + برچسب A/B/C)
- [ ] Price Suggestion هوشمند (بر اساس تاریخچه‌ی قیمت منطقه‌ای + نوع مصالح + کیفیت)
- [ ] محاسبه‌ی هزینه‌ی حمل بر اساس فاصله‌ی واقعی مبدأ/مقصد و افزودن به تصمیم خرید
- [ ] پیام‌رسانی درون‌اپ بین خریدار و فروشنده (به‌جای افشای مستقیم شماره)
- [ ] امتیازدهی/نظرات بعد از معامله (لایه‌ی اعتماد)
- [ ] داشبورد «چرا این پیشنهاد؟» برای هر match (توضیح‌پذیری تصمیم AI)
- [ ] اعلان (نوتیفیکیشن) وقتی مصالح مورد نیاز پیدا شد

## فاز ۳ — V2 و رشد (۳ تا ۶ ماه بعد)
هدف: تبدیل شدن از مارکت‌پلیس منطقه‌ای به Materials Intelligence Network.

- [ ] موتور matching خودکار real-time (به‌جای rule-based ساده)
- [ ] escrow سبک یا هماهنگی پرداخت امن بین طرفین
- [ ] اپلیکیشن موبایل (یا PWA)
- [ ] گسترش به شهرهای دیگر و دسته‌های بیشتر مصالح
- [ ] اشتراک B2B برای تأمین‌کنندگان بزرگ/انبارها (دسترسی API، اولویت در جست‌وجو)
- [ ] انتشار «شاخص قیمت منطقه‌ای مصالح دست‌دوم» به‌عنوان محصول اطلاعاتی مستقل
- [ ] API عمومی برای اتصال به نرم‌افزارهای مدیریت پروژه‌ی ساختمانی

## معیارهای موفقیت (KPI هر فاز)
| فاز | معیار کلیدی |
|---|---|
| ۰ | ≥۱۰ پیمانکار تمایل به ثبت مصالح مازاد اعلام کنند |
| ۱ | اولین ۳ معامله‌ی واقعی موفق در منطقه‌ی پایلوت |
| ۲ | نرخ پذیرش پیشنهاد قیمت AI ≥ ۶۰٪، رضایت کیفیت ≥ ۸۰٪ |
| ۳ | رشد ماهانه‌ی آگهی‌های فعال + شروع درآمد کمیسیون/اشتراک B2B |

## مدل درآمدی (یادآوری از سند اولیه)
کمیسیون روی هر تراکنش موفق + اشتراک B2B برای تأمین‌کنندگان/انبارهای بزرگ.
