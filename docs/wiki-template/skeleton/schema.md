# Schema — قوانین ساختار ویکی این پروژه

> این فایل را بعد از کپی کردن قالب، برای قواعد خاص پروژه‌ی خودت دقیق‌تر کن.
> نسخه‌ی کامل قوانین در `../RECIPE.md` (یا معادلش در ریشه‌ی پروژه) است؛ اینجا فقط چکیده‌ی عملیاتی است.

## ساختار پوشه
```
docs/wiki/
  schema.md      # همین فایل
  overview.md    # یک‌نگاه کلی پروژه (≤۴۰۰ کلمه)
  index.md       # کاتالوگ همه صفحات
  log.md         # تاریخچه‌ی append-only تغییرات ویکی
  entities/      # مدل‌ها، سرویس‌ها، صفحات کلیدی
  concepts/      # flowها، الگوها، تصمیم‌های معماری
  sources/       # (اختیاری) خلاصه‌ی فایل‌های پرارجاع
```

## قواعد نام‌گذاری و لینک
- نام فایل: lowercase + hyphen، مثلاً `user-model.md`.
- لینک‌ها به سبک Obsidian: `[[entities/user]]` بدون `.md`.

## چه وقت صفحه‌ی جدید بساز
فقط اگر ≥۳ جای دیگر به آن لینک می‌دهند یا concept مستقل و پرحجمی است؛ در غیر این صورت صفحه‌ی موجود را آپدیت کن.
