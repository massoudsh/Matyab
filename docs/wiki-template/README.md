# قالب ویکی دانش پروژه (Vault Template)

قالب آماده‌ی «ویکی دانش پروژه» — همان سیستمی که برای دانش زنده‌ی این پروژه استفاده می‌شود، به‌صورت
عمومی و قابل‌کپی برای هر پروژه‌ی دیگر. این نسخه در متریاب هم به‌عنوان سند مرجع نگه‌داری می‌شود و هم
مبنای صفحات `docs/wiki/*.md` این ریپو (که به [ویکی گیت‌هاب](../../../wiki) هم sync می‌شود) و دانش
داخلی ایجنت است.

## استفاده در یک پروژه‌ی جدید
1. پوشه‌ی `skeleton/` این قالب را داخل پروژه‌ی جدید کپی کن (پیشنهاد مسیر مقصد: `docs/wiki/`).
2. محتوای `RECIPE.md` را به‌طور کامل کپی کن و در ابتدای فایل `CLAUDE.md`/`AGENTS.md` همان پروژه
   (یا هر جای دیگری که system prompt پروژه را می‌سازد) پیست کن.
3. از سشن بعدی، ایجنت خودش طبق قوانین `RECIPE.md` صفحات `overview.md` و `index.md` را می‌خواند، و
   بعد از هر تغییر معنایی در کد، ویکی را به‌روز نگه می‌دارد.

## محتوای این قالب
- `RECIPE.md` — متنی که باید کپی/پیست شود (دستورالعمل کامل برای ایجنت).
- `skeleton/schema.md` — قوانین کامل ساختار و لینک‌گذاری (خودِ ایجنت بعداً آن را برای هر پروژه دقیق‌تر می‌کند).
- `skeleton/overview.md`, `skeleton/index.md`, `skeleton/log.md` — اسکلت خالی با placeholder.
- `skeleton/entities/`, `skeleton/concepts/`, `skeleton/sources/` — پوشه‌های خالی آماده برای صفحات آینده.

## استفاده در همین پروژه (متریاب)
- **ویکی گیت‌هاب** (`gh wiki`, صفحه‌ی عمومی برای هرکسی که ریپو را باز کند): محتوای `docs/wiki/*.md` —
  یعنی نسخه‌ی «محصول‌محور» (معماری، مدل داده، API، AI) — به ویکی گیت‌هاب push می‌شود.
- **دانش داخلی ایجنت (Noqte knowledge)**: پوشه‌ی `.noqte/wiki/` (gitignore‌شده، فقط داخل پلتفرم)
  دقیقاً طبق `RECIPE.md` همین قالب نگه‌داری می‌شود — entity/concept per model و service، برای این‌که
  هر سشن جدید بدون re-scan کل کدبیس شروع شود.

هر دو خروجی از یک منبع الگو می‌آیند (این پوشه)؛ اگر روزی قوانین این قالب عوض شد، هر دو باید هماهنگ به‌روز شوند.
