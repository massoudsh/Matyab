# Epic 17 — اپلیکیشن موبایل/PWA و گسترش جغرافیایی
لیبل: `epic`, `v2`, `frontend`, `infra`

مسئله (روادمپ فاز ۳): پیمانکاران و انبارداران بیشتر از موبایل استفاده می‌کنند؛ فعلاً فقط وب واکنش‌گرا (RTL، Tailwind)
داریم بدون قابلیت نصب/آفلاین/نوتیفیکیشن native. گسترش به شهرهای جدید هم نیاز به داده‌ی منطقه‌ای بیشتر دارد
(دسته‌بندی، نرخ حمل، تأمین‌کننده‌های محلی).

### ISSUE-1702: Push Notification موبایل
**شرح:** تکمیل E14 با کانال push (وب Push API) برای MATCH_FOUND و PROCUREMENT_CRITICAL — نه فقط in-app.
**معیار پذیرش:**
- [ ] اشتراک push در PWA + ذخیره‌ی subscription per user
- [ ] ارسال push هم‌زمان با ساخت `Notification` در سرویس‌های موجود

---
### ISSUE-1703: پشتیبانی چند شهر/منطقه در فیلترها
**شرح:** فیلترها و پیش‌فرض‌های فعلی (مثلاً نرخ حمل ثابت در `matching.service.ts`) برای تهران کالیبره شده؛ باید per-region پیکربندی‌پذیر شود.
**معیار پذیرش:**
- [ ] نرخ حمل به ازای منطقه از دیتابیس/کانفیگ خوانده شود، نه هاردکد
- [ ] فیلتر شهر در تمام صفحات لیست (Listings/Requests/Suppliers) کامل و تست‌شده باشد
