# Epic 3 — آگهی عرضه (Listings)
لیبل: `epic`, `mvp`, `backend`, `frontend`, `db`

---
### ISSUE-301: مدل داده‌ی Listing
**شرح:** مصالح مازادی که یک پروژه ثبت می‌کند.
**معیار پذیرش:**
- [ ] فیلدها: دسته، مقدار، واحد، عکس‌ها (آرایه‌ی URL)، توضیحات، قیمت پیشنهادی فروشنده، وضعیت، پروژه‌ی مرتبط
- [ ] enum وضعیت: `ACTIVE`, `MATCHED`, `SOLD`, `EXPIRED`

---
### ISSUE-302: آپلود عکس مصالح
**لیبل:** `backend`
**شرح:** آپلود عکس به object storage (S3-compatible) و ذخیره‌ی URL.
**معیار پذیرش:**
- [ ] محدودیت حجم و فرمت فایل
- [ ] حداقل ۱ و حداکثر ۶ عکس در هر آگهی

---
### ISSUE-303: API ثبت/ویرایش/فهرست آگهی
**شرح:** CRUD کامل روی Listing با فیلتر دسته/شهر/بازه‌ی قیمت.
**معیار پذیرش:**
- [ ] `GET /listings` با query params فیلتر
- [ ] `POST /listings`, `GET /listings/:id`, `PATCH /listings/:id`
- [ ] فقط مالک پروژه اجازه‌ی ویرایش دارد

---
### ISSUE-304: صفحه‌ی فرم ثبت آگهی در فرانت
**لیبل:** `frontend`
**معیار پذیرش:**
- [ ] فرم چندمرحله‌ای (دسته → مشخصات → عکس → قیمت)
- [ ] پیش‌نمایش قبل از ثبت نهایی

---
### ISSUE-305: صفحه‌ی فهرست و جست‌وجوی آگهی‌ها
**لیبل:** `frontend`
**معیار پذیرش:**
- [ ] کارت آگهی با تصویر، دسته، قیمت، شهر
- [ ] فیلتر دسته/شهر/قیمت در سایدبار
