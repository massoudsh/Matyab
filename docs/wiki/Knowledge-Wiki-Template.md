# قالب ویکی دانش پروژه (Vault Template)

این پروژه از یک الگوی ثابت برای نگه‌داشتن «دانش زنده‌ی پروژه» (کنار کد، نه به‌جای کد) استفاده می‌کند —
هم برای مستندات محصول‌محور قابل‌مشاهده در همین ویکی، هم برای دانش داخلی ایجنت. این الگو خودش هم به‌عنوان
یک قالب قابل‌کپی برای پروژه‌های دیگر نگه‌داری می‌شود.

## کجا استفاده شده
1. **این ویکی گیت‌هاب** — صفحات محصول‌محور (معرفی محصول، معماری، مدل داده، API، هوش مصنوعی، مدل کسب‌وکار)
   که در ریپوی اصلی زیر `docs/wiki/` نگه‌داری و از آنجا به این ویکی sync می‌شوند.
2. **دانش داخلی ایجنت (Noqte knowledge)** — نسخه‌ی entity/concept-محور دقیق‌تر، برای این‌که هر سشن کاری
   بدون re-scan کردن کل کدبیس شروع شود؛ داخل پلتفرم نگه‌داری می‌شود (خارج از این ریپو گیت).
3. **قالب قابل‌کپی برای پروژه‌های دیگر** — فایل کامل دستورالعمل + اسکلت خالی، در ریپوی اصلی زیر
   [`docs/wiki-template/`](https://github.com/massoudsh/Matyab/tree/main/docs/wiki-template).

## قوانین خلاصه
- `overview.md` (خلاصه ≤۴۰۰ کلمه) و `index.md` (کاتالوگ صفحات) همیشه اول خوانده می‌شوند — نه کل کدبیس.
- هر entity/concept مهم یک صفحه‌ی مستقل دارد؛ صفحه‌ی جدید فقط وقتی ساخته می‌شود که واقعاً محتوای مستقل
  و پرارجاع داشته باشد (قانون کامل در `RECIPE.md`).
- بعد از هر تغییر معنایی در کد (نه typo/فرمت)، صفحه‌ی مرتبط به‌روزرسانی و یک خط در `log.md` اضافه می‌شود.
