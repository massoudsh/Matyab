# مدل کسب‌وکار

## بازار هدف
پیمانکاران، انبارداران و تأمین‌کنندگان مصالح ساختمانی در پروژه‌های ساختمانی ایران. شروع با یک منطقه (پیشنهاد: تهران) و چند دسته‌ی پرتراکنش مصالح.

## مدل درآمدی
1. **کمیسیون تراکنش**: درصدی از هر معامله‌ی موفق بین خریدار و فروشنده.
2. **اشتراک B2B**: تأمین‌کنندگان و انبارهای بزرگ برای دسترسی گسترده‌تر (آگهی نامحدود، اولویت در نتایج جست‌وجو، دسترسی API، گزارش‌های بازار).

## مزیت رقابتی
- Quality Scoring اختصاصی مصالح ساختمانی (نه آگهی عمومی بدون معیار مثل دیوار).
- قیمت‌گذاری شفاف مبتنی بر داده، نه چانه‌زنی کور.
- محاسبه‌ی هزینه‌ی حمل به‌عنوان بخشی از تصمیم خرید.
- اثر شبکه‌ای دوطرفه: هر پروژه هم می‌تواند عرضه‌کننده باشد هم تقاضاکننده.

## مسیر رشد
```
پایلوت یک منطقه/چند دسته
      │  اثبات اعتماد و نقدشوندگی
      ▼
گسترش جغرافیایی + دسته‌های بیشتر
      │  رشد داده‌ی قیمت → دقت بالاتر Price Suggestion
      ▼
Materials Intelligence Network
(شاخص قیمت منطقه‌ای، API عمومی، مشتریان سازمانی)
```

## ریسک‌های کلیدی و راهکار
| ریسک | راهکار |
|---|---|
| بی‌اعتمادی به کیفیت مصالح دست‌دوم | Quality Scoring + رده‌بندی شفاف + نظرات بعد از معامله |
| کمبود moment داده‌ی قیمت در شروع | جمع‌آوری دستی قیمت بازار در فاز ۰، به‌روزرسانی مداوم از تراکنش‌های واقعی |
| نوسان شدید قیمت مصالح در ایران | به‌روزرسانی مکرر PriceHistory، نمایش بازه به‌جای عدد قطعی |
| هزینه‌ی حمل باعث بی‌صرفگی معامله شود | محاسبه‌ی حمل همیشه بخشی از پیشنهاد نهایی، نه جداگانه |
