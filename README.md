# متریاب (MatYab)
### کوپایلوت هوشمند تأمین، قیمت‌گذاری و استفاده‌ی مجدد از مصالح ساختمانی

> «متریاب» از ترکیب «متریال (مصالح)» + «یاب (پیدا کردن)» ساخته شده — دستیاری که مصالح مازاد، دست‌دوم و قابل بازیافت را پیدا می‌کند، ارزش واقعی‌شان را می‌سنجد، و پروژه‌های خریدار و فروشنده را به هم وصل می‌کند.

## مسئله (خلاصه)
مصالح مازاد یک پروژه، نیاز پروژه‌ی دیگری است — اما این دو همدیگر را پیدا نمی‌کنند. نبود بازار شفاف، نبود اعتماد، نبود quality scoring و نبود قیمت‌گذاری منصفانه باعث می‌شود مصالح یا هدر برود یا ارزان‌فروشی شود، و خریدار مجبور شود گران‌تر و نو بخرد.

## راه‌حل
یک مارکت‌پلیس + کوپایلوت تصمیم که:
- مصالح مازاد پروژه‌ها را ثبت و دسته‌بندی می‌کند (آگهی عرضه).
- نیاز پروژه‌های دیگر را ثبت می‌کند (آگهی تقاضا).
- با هوش مصنوعی کیفیت و قابلیت استفاده‌ی مجدد را از روی عکس و توضیحات امتیاز می‌دهد (Quality Score).
- قیمت منصفانه پیشنهاد می‌دهد (بر اساس تاریخچه‌ی قیمت، منطقه و نوسان بازار).
- هزینه‌ی حمل بر اساس فاصله را محاسبه و در تصمیم لحاظ می‌کند.
- عرضه و تقاضا را match می‌کند و به هر طرف پیشنهاد مشخص می‌دهد: «این گزینه به‌صرفه است»، «این یکی ریسک کیفیت دارد»، «این خرید با حمل به‌صرفه نیست».

## ساختار مخزن
```
matyab/
├── frontend/     # Next.js + TypeScript + Tailwind (RTL فارسی)
├── backend/      # Node.js + TypeScript + Express + Prisma
├── db/           # اسکیمای خام دیتابیس (PostgreSQL) و seed
└── docs/         # roadmap, wiki, issues
```

## استک فنی
| لایه | فناوری |
|---|---|
| Frontend | Next.js 14 (App Router)، TypeScript، TailwindCSS، RTL |
| Backend | Node.js، TypeScript، Express، Prisma ORM |
| Database | PostgreSQL (+ افزونه‌ی pgvector برای مچینگ معنایی) |
| کش/صف | Redis (کش قیمت، صف پردازش تصویر برای quality scoring) |
| ذخیره‌ی فایل | S3-compatible object storage (تصاویر مصالح) |
| هوش مصنوعی | سرویس‌های جدا برای Quality Scoring، Price Suggestion، Matching Engine (پشت API داخلی) |

## راه‌اندازی محلی (توسعه)
> نصب dependency و build سنگین باید طبق سیاست پروژه روی سرور SSH انجام شود، نه داخل این کانتینر. فایل‌های اسکلت زیر آماده‌ی `npm install` روی سرور هستند.

```bash
# backend
cd backend && cp .env.example .env
# frontend
cd frontend && cp .env.example .env
```

جزئیات کامل معماری، مدل داده و API در [wiki](./docs/wiki/Home.md) است.
